Write safety

Write commands are disabled until you tick the acknowledgement on the Dashboard. Reading registers is always available.

Setpoint register 0173 uses a raw value of 250 for 25.0 °C when the configured sensor type uses 0.1 °C resolution.

Regulation register 0180: write 0 to turn regulation off, 1 to turn it on, or 2 to pause. Turning regulation on may energize a connected heater or actuator.

The page cannot guarantee that a physical heater is safe. Check the controller mode, sensor, output wiring, and load before enabling regulation.
